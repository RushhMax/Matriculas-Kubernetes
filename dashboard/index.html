Guía rápida para correr todo

# 1) Credenciales AWS (Learner Lab → AWS Details → AWS CLI) en ~/.aws/credentials
aws sts get-caller-identity

# 2) Infraestructura
cd infrastructure/infrastructure/k3s
terraform init && terraform apply          # ajusta allowed_http_cidr a tu IP /32

# 3) Despliegue (en la EC2 por SSM, o con kubeconfig local)
kubectl apply -k infrastructure/k8s/overlays/aws-k3s

# 4) Verificar
kubectl -n unsa-matricula get pods,hpa,svc,ingress

# 5) Este dashboard: botón ⚙ Conexión → descargar bridge.py y ejecutarlo
python3 bridge.py
